# Single-source narrative verification — 8 November 2026

Root cause: the LLM schema omitted issue titles and completion criteria; rendering always supplied template titles, suppressed model explanation/action for unverified findings, and generated fallback issue paragraphs for every unselected finding. Review fallback and renderer fallback were separate competing generators. Daily delivery also had an independent actions map.

Current triage-v4 requires title, explanation, recommended_action and completion_criterion. Missing/blank fields retry then switch the entire review to deterministic mode. Artifact loading revalidates current AI fields and successful generation. Code-owned findings, URLs, metrics, statuses and evidence references remain unchanged. Templates are now used at fallback generation before serialization; new rendering consumes only saved narrative. The explicit old-fallback adapter remains for historical artifacts. Historical AI fields are never silently supplemented. Unselected/resolved findings appear as factual records, preserving bounded output limits.
